## Fixed dependency API and artifact direction

T047 Interface A/B is normative and read-only to this task. Verify source views,
consume rows, acquire its writer and reserve/settle tickets; never mutate source
or allocation journals directly. Runtime owns its separate contiguous immutable
driver events, global arrival/identity/counter records, tick/start/stop completion
and admitted-subplan mappings. No mutable index overrides a committed chain.
Hash direction is source view -> driver admission -> admitted chunk -> core plan/
enrollment -> native claim/attempt -> verified packet/core receipt -> driver
completion. Each stores predecessor hashes, never future mutually recursive hashes.

The exact bound native port is:

```
collect_one(store, sources, ordinal, *, runtime, private_dir, live=False,
            manifest=None, clock=None, transport=None, route=None,
            policy=None, hooks=None, engine=None)
recover(store, sources, runtime, *, private_dir, now=None)
read_prepared(runtime, private_dir)
code_manifest()
report(runtime)
```

collect_one validates synchronously and returns an awaitable for valid live work.
The synchronous policy has before_attempt(proposed)->same/tightened permit/None,
observe(event)->None. Proposed safe fields include role/host, plan/code/ordinal/
attempt/claim identity, date, allowance/private bytes and deadlines. Only
expires_mono/packet_deadline/external_deadline may be tightened. Events are
native_invocation, headers, attempt_end and child_retired with safe clock/status/
hash fields. Clock has utc(), mono(), async sleep(seconds). The driver never
changes request_deadline or treats report() as raw-integrity verification.
Production passes default native transport/engine/route and frozen manifest;
fixture-only Python injections never become config/CLI knobs.
